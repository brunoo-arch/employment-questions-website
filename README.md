# Preguntas sobre Empleo

Sitio web de preguntas frecuentes sobre empleo con consejos, recursos y formulario de contacto.

## Cómo ver la página

Abre `index.html` en tu navegador.

## Estructura

- `index.html` — contenido principal
- `styles.css` — estilos del sitio
- `script.js` — interactividad de FAQ y formulario

## Descripción

La página incluye:

- encabezado con navegación
- sección hero
- preguntas frecuentes con acordeón
- consejos prácticos
- recursos de empleo
- formulario de contacto con validación simple

## Autor

Proyecto creado para apoyar a personas que buscan orientación laboral.
